\# ⚡ VoltX – Die Cheat-Community



VoltX ist eine Community-Plattform für Cheats, Hacks und Tools.



\## 🔥 Features



\- ✅ Login \& Registrierung

\- ✅ Shop mit Cheats

\- ✅ Täglicher Bonus

\- ✅ Profil mit Avatar \& Bio

\- ✅ Admin-Panel

\- ✅ Discord-Integration



\## 🛠️ Technologien



\- Backend: Node.js, Express, Supabase

\- Frontend: HTML, CSS, JavaScript



\## 🚀 Installation



```bash

cd backend

npm install

npm run dev
